## Verified layout, bounded to these files

Matching four-byte little-endian Fortran record markers enclose six metadata
payloads of 320, 76, 160, 160, 2564 and 7276 bytes, followed by 9876-byte data
payloads. The species header contains `int32 ny=160`, then 160 binary64 Z values,
then 160 binary64 A values. All are integral, unique `(Z,A)` pairs. This does not
encode isomer identity or establish the generating rates/masses.
The flux header contains `int32 909` and two arrays of 909 int32 species indices.

| Data-payload byte offset | Inspected source meaning | Interpretation limit |
| --- | --- | --- |
| 0 | int32 integration step | Not a unique record ID; NSE repeats step numbers |
| 4, 12, 20 | binary64 time, T9, density | Source indicates s, GK, g/cm³; generating association remains unproven |
| 28 | binary64 internal `tdel` | Not the interval between saved outputs |
| 36 | binary64 stored `edot` | Source-defined internal-step energy rate; unqualified target |
| 44 | 160 binary64 `y` values | Source uses molar abundance Y; mass fraction is A·Y |
| 1324 | 909 binary64 flux values | Preserved layout observation, not a qualified flux task |
| 8596 | 160 binary64 stored derivatives | No accepted-state RHS qualification |

The first data **marker** is at file byte 10604; its payload begins at 10608.
Raw `Z||A` bytes share SHA-256
`61b7cd1622dad1895a173ed5ade43145c3cd451d91779f21d78c82d42b5fdf25`.

accepted conservation tolerance or proof of full physical accuracy.

## Bounded remote provenance recovery

After the initial local audit, the maintainer supplied the original Perlmutter
location and offered useful additional copies. Read-only access succeeded. The
selected slab has original initial-abundance and particle-history symlinks whose
targets exist (about 44 MB and 2.84 GB respectively); its extrema link is dangling (not a demonstrated runtime dependency).
Only 28 small controls/build/slab-mapping metadata and candidate SN160 input
files (1,719,886 bytes) were copied into separate ignored audit storage, with
local hashes. The multi-GB history and raw outputs were not copied.

These current files are recoverable evidence candidates, not historical run
receipts. Independent inspection of the recovered `nets4` reports 160 species, 176
weak-rate entries and **zero neutrino-rate entries**, corroborated by processed
reaction flags. `xnet_data.f90:584–594` and `xnet_integrate.f90:597` skip neutrino
input/rates when that count is zero. Thus absent `netneutr` is expected for these
candidate tables; a control flag alone does not prove active neutrino capture.
This revises the initial source-only concern, conditional on input association.
Weak reactions still preclude imposing fixed Ye. No dedicated extrema read exists
in the inspected Fortran sources: `xnet_controls.f90:351–364` consumes the first
abundance/history filename pair, and `model_input_pdata.f90:150–163,192–210` uses
`/extrapolation/tau` inside the history file. The trailing dangling extrema path
is not established as a runtime dependency.

The initial statement that inputs are absent applies to the supplied
local collection; recovery from the remote location is now active. A system-Python
metadata read could not import h5py; it changed no inputs. Subsequent bounded
reads used Perlmutter's existing Python/h5py module, not the producer. Parent
composition/history files were hashed remotely; only one tracer's selected input
slices (about 0.63 MB) were retained locally, with their slice/hash recipe. The
selected remote raw pair, control, executables and five inspected source files
match the supplied local copies byte-for-byte. This corroborates current-file
identity, not historical generation; optional remote Git inspection was refused
by its ownership check and no remote setting was changed.

For pair B, the original input has all native abundances zero and an appended
initial Ye. Source `model_input_pdata.f90:591–596` therefore selects an NSE
initialization fallback independently of the separate 8 GK NSE-advance threshold.
Initial binary time/T9/density exactly match the selected history first frame;
composition-derived Ye agrees with the appended initialization Ye, which differs
from the history's first Ye. Preserve these distinct quantities; do not replace
composition Ye with the history value or infer fixed Ye. Full initial NSE
composition was not reproduced: no NSE solver/producer was executed. Zero input
abundances mean this case supplies no measurement of ordinary truncation error.
The selected history's extrapolation tau and inspected formula also corroborate
its extension to final time 100; this is not reference-convergence evidence.
The independent local recomputation is `.local/phase1-audit/compare_selected_input.py`. Private remote paths,
submission/account details and recovered metadata remain local in
`.local/phase1-audit/perlmutter-recovery/`; no producer execution, new run or
scientific qualification is implied.

## Physical interpretation and exclusions

Locations below refer to the **inspected bundled snapshot**, not a claim about
the generating build; see the hashes above and local inventory.

do not label it deposited heating. D-007 cannot select authoritative tolerances or
