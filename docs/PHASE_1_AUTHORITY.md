The instruction authorizes S01–S03 in the existing [roadmap](ROADMAP.md#phase-1--verified-data-semantics-provenance-ingestion-and-partitions)
and [backlog](BACKLOG.md), including branches/worktrees, CRUCIBLE edits, justified

exclusions, provenance gaps and D-004/D-005/D-007 when supported by evidence.

interpretations and synthetic public fixtures until real-fixture redistribution

limited within-simulation exploration, not simulation-level independence.

record source/revision and access failures. If the actual template is inaccessible,
label the card provisional without claiming conformance. Keep private paths and
unapproved metadata local. A public card does not release its data. Add model-card
requirements to Phase 2 and subsequent model-artifact lifecycle; create no
trained-model or agent card in Phase 1.

Use the adopted issue → checks → self-review → draft PR → fresh exact-candidate
independent review → disposition/repair → human merge → integration cycle.

delegation. Scientific acceptance is separate from implementation permission.

Luna, and Astra requires the canonical bounded escalation record. No removed
resource cap or per-command accounting is reinstated.

model development/training, reduction-architecture selection, paid services or
deployment. If reference execution is needed, prepare the exact bounded proposal
and obtain authorization before execution. Bootstrap publication approval does
not establish dataset redistribution rights.
